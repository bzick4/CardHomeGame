# Арт-пакет и план интеграции — «Дом на ночь»

Подготовлено в отдельном чате с Claude (нарезка и подготовка арта). Этот файл — задание для чата в Claude Code,
который будет встраивать всё в проект. Все картинки уже лежат по путям `Assets/Resources/Art/...`.

## Что лежит и где

| Папка (в `Assets/Resources/Art/`) | Что | Примечание |
|---|---|---|
| `RoomArt/` | 14 комнат + `Empty`, `Broken`, 384×384, прозрачные углы | Арт для лица карт комнат. `Rooms/` (иконки доски 156×148) не трогали |
| `Backs/Theme0..Theme10.png` | Рубашки без рамки, 300×420 | Код уже ищет эти имена. 0..9 = порядок `HouseDatabase.All`, 10 = Странник |
| `Frames/Frame0..Frame8.png` | Рамки кругов (Базовая…Легендарная), холст **380×516**, карта 300×420 стоит со смещением (40, 48) | Середина прозрачная. Одна рамка и для лица, и для рубашки. Крылья/короны выходят за карту — это запас холста |
| `Cards/TextPanel.png` | Пергамент под описание | 9-slice, Border ≈ 34 px со всех сторон, Image Type = Sliced |
| `Map/Campaign.png`, `Map/CampaignWide.png` | Фоны карты кампании 9:16 и 16:9 | |
| `Map/Nodes/` | `PlatformOpen/Current/Locked` + значки `Elite, Event, Fair, Rest, Treasure, Shrine, Portal, Boss` | Значки уже со своей подставкой — ставить без платформы |
| `Houses/<Id>.png` | 10 превью домов без подписей, 300×380 | Для окна дома / узлов-домов |
| `Fx/` | 39 эффектов с альфой | `TileOk/TileBad/TileTarget` — подсветка клеток; `Coins, Heart, MoodUp, MoodDown, Shield, Dust, Explosion, GhostSmoke, Sparkles, BeamGold`… |
| `Wander/` | `MapBackground(Wide).png` 2560px, `Node{Elite,Event,Fair,Rest,Boss}.png`, `Pedestal.png` | Имена под `MenuArt.WanderArt(...)` |
| `Locations/<Id>.png`, `<Id>Wide.png` | Фоны игрового поля по домам, 2560px | Полный набор: 10 домов × 2 ориентации |

`Assets/Scripts/Data/CampaignPoints.cs` — 10 точек домов на фонах кампании (доли картинки, x слева, y снизу, как anchor).

`Extra/` — не для Resources: `HallInterior.png` (лишний фон-интерьер, можно для меню/магазина) и `previews/` (как должно выглядеть).

**Импорт:** фоны `Locations/*`, `Wander/MapBackground*`, `Map/Campaign*` — Max Size 4096 (иначе Unity ужмёт до 2048).

## Задачи по коду

1. **Карта = слои.** `CardView`: под рамкой — содержимое (лицо или рубашка `Theme<N>`), сверху `Frames/Frame<tier>`
   (tier = `Card.FrameTier(level)` для комнат, круг для рубашек). Рамка Image размером карта × (380/300, 516/420),
   по центру со смещением как на холсте. Переворот меняет только содержимое.
   - Данные: ScriptableObject `CardData` (комнаты/гости) + `FrameTier` ×9. Не 234 ассета, а 26 + 9.
2. **Лицо карты комнаты** (300×420): арт `RoomArt/<Type>` сверху (~2/3), пергамент `TextPanel` на всю ширину снизу (с y≈256 и уходит под рамку),
   красная лента с названием на стыке (y 236–274), описание на пергаменте (автоподбор 17→10).
   **Схема дверей** — тёмная плитка 48×48 с золотыми проходами из центра к дверям, центр ≈ (214, 94) от верх-лево. Поворачивается с картой.
   Безопасная зона текста: ~30 px от боков и ~60 px от низа (нижние камни Рубиновой/Легендарной рамок).
3. **Лицо карты гостя:** фон `Cards/Backdrop`, персонаж в полный рост (голова в кадре, ноги под лентой), значок роли слева вверху ≈(73, 93),
   солнце (настроение) и луна (выносливость) у нижнего края арта. Угрозы: солнце = награда «+5/+4», вместо луны — сердце «−1».
   Описания можно укоротить (статы уже на значках).
4. **Фоны поля:** показывать `Locations/<Id>` / `<Id>Wide` на игровом экране (сейчас они предзагружаются в `ArtStore.ForLevel`, но нигде не рисуются).
5. **Кампания:** фон `Map/Campaign(Wide)` + 10 точек из `CampaignPoints`, платформы Open/Current/Locked.
6. **Странствие:** фон `Wander/MapBackground(Wide)`. В `GameView.Wander.NodePos` ряды сейчас −540…+570 — переложить на доли фона:
   вертикаль y от 0.80 до 0.135 высоты (снизу вверх), разброс x ±360 при 1080 ширине;
   горизонталь y от 0.84 до 0.19, x ±~340 при 1920. Босс встаёт в ворота крепости. Узел-дом = `Pedestal` + маленькое превью `Houses/<Id>`.
7. **Эффекты** через DOTween (вспышка/подъём/затухание): `TileOk/TileBad` при перетаскивании, `Coins`/`Heart`/`MoodUp`/`MoodDown` ночью,
   `Shield` + `Dust` для ловушек, `GhostSmoke` для призраков, `Sparkles` для улучшения, `BeamGold` для текущей точки кампании.
