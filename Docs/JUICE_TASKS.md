# Задание для Claude Code — «сочность» (game feel) на DOTween

Хотим ощущения уровня ассета **Feel** (More Mountains), но **без него**: только DOTween, который уже в проекте.
Причины: весь UI строится кодом, репозиторий публичный (платный ассет туда класть нельзя), DOTween уже везде.
Правила проекта прежние: без Update и корутин, всё на событиях `GameController` и твинах, `SetLink` на каждый твин,
эффект не ломает игру, если картинки нет. Коммит после каждого блока.

Если `CODE_TASKS.md` ещё выполняется — этот файл делать **после** него (используются новые кнопки, иконки и `Art/Fx`).

## Блок 1. Библиотека `Juice` — переиспользуемые «фидбеки»

Новый файл `Assets/Scripts/UI/Juice.cs`, `public static class Juice`. Каждый метод возвращает `Tween`/`Sequence`,
сам гасит предыдущий такой же твин на цели (`DOKill(complete: true)` по id), чтобы эффекты не копились при частых вызовах.

| Метод | Что делает | Где пригодится |
|---|---|---|
| `Punch(RectTransform t, float strength = 0.12f, float dur = 0.25f)` | `DOPunchScale` вокруг текущего масштаба | Карта легла на поле, кнопка нажата, счётчик изменился |
| `Squash(RectTransform t, float amount = 0.15f, float dur = 0.3f)` | Сплющивание по Y + растяжение по X и обратно с `OutElastic` | Приземление карты, прыжок жетона гостя |
| `Shake(RectTransform t, float strength = 18f, float dur = 0.35f, int vibrato = 22)` | `DOShakeAnchorPos`, возврат точно в исходную позицию | Ловушка, сломанная комната, недовольный гость |
| `ScreenShake(float strength, float dur)` | `Shake` по корневому контейнеру игрового экрана (не по Canvas!) | Сильные события: босс, поломка, конец ночи с потерей |
| `Flash(Graphic g, Color c, float dur = 0.18f)` | Цвет → `c` → исходный | Клетка, кнопка, рамка карты |
| `Flicker(Graphic g, int times = 3, float dur = 0.3f)` | Мигание альфой | Предупреждение: нельзя поставить, мало ходов |
| `Pulse(RectTransform t, float scale = 1.06f, float period = 0.9f)` | Бесконечное «дыхание» `Yoyo`, вернуть `Tween` для остановки | Кнопка «НОЧЬ», когда ходы кончились; играбельные карты |
| `PopIn(RectTransform t, float dur = 0.3f)` / `PopOut(...)` | Появление/исчезновение с `OutBack`/`InBack` | Окна, иконки, награды |
| `FloatText(RectTransform parent, Vector2 pos, string text, Color c, Sprite icon = null)` | Иконка + число, вылетает вверх с подскоком и тает (обобщение текущего `FloatingNumber`) | «+3 ● », «−1 ♥», «+2 настроения» |
| `FlyTo(RectTransform item, RectTransform target, float dur, Action onArrive)` | Полёт по дуге (`DOPath` с промежуточной точкой выше) + уменьшение, на прибытии — `Punch(target)` | Монеты в счётчик золота, сердце в репутацию, карта в колоду |
| `CountTo(Text label, int from, int to, float dur, string format)` | Число «докручивается», в конце `Punch` | Золото, итоги ночи |
| `HitStop(float dur = 0.08f)` | Короткая пауза: `DOTween.timeScale` → 0.05 и обратно; сам твин паузы с `SetUpdate(true)` | Поимка вора/волка, удар босса |
| `SlowMo(float scale = 0.35f, float dur = 0.6f)` | Замедление `DOTween.timeScale` с плавным возвратом | Последний гость ночи, победа |

Важное:
- **Игровая логика не должна зависеть от `timeScale`** — проверь, что `HitStop/SlowMo` трогают только `DOTween.timeScale`, а не `Time.timeScale`,
  и что важные для логики задержки/последовательности не ломаются (если ломаются — помечать такие твины `SetUpdate(true)`).
- Настройка «Меньше эффектов» в настройках (`SaveSystem`): выключает `ScreenShake`, `HitStop`, `SlowMo`, `Flicker`, остальные — силой ×0.5.
  Для людей, которых укачивает, и для слабых телефонов.
- Все силы и длительности — константы в одном месте `Juice.Tuning` (static class с полями), чтобы потом легко крутить.

## Блок 2. Привязка к событиям игры

Найди обработчики событий `GameController` в `GameView*` (`RoomPlaced`, `RoomBroken`, `GuestPlayed`, `GuestWalk`, `PhaseChanged`, `Changed`)
и звуки `Sfx.*` — эффекты ставь рядом со звуками, это хорошие якоря.

**День**
- Карта взята из руки — лёгкий `Punch` 0.06 + тень под картой больше/мягче (карта «приподнялась»).
- Карта легла на клетку (`RoomPlaced`) — `Squash` плитки + `Fx/TileOk` на клетке + `Punch` соседних соединённых плиток с задержкой 0.04 с по цепочке (видно, что двери сошлись).
- Нельзя поставить (бросок мимо / двери не сходятся) — `Shake` карты 10 px + `Flash` клетки красным + `Fx/TileBad`, карта пружинит обратно в руку.
- Поворот комнаты — поворот с `OutBack` и `Punch` 0.05 в конце.
- Ходы кончились — `Pulse` кнопки «НОЧЬ» (остановить при нажатии).
- Улучшение карты в лавке — `Punch` + `Fx/Sparkles` + смена рамки с `Flash` белым.

**Ночь**
- Начало ночи — `SlowMo` 0.5 на время затемнения неба; рубашка гостя переворачивается с `Squash`.
- Гость сыгран (`GuestPlayed`) — карта летит на крыльцо `FlyTo`, на приземлении `Squash`.
- Шаг гостя по комнате — жетон делает маленький прыжок (`DOJumpAnchorPos`, 1 прыжок, высота ~12% клетки) + `Squash` при приземлении.
- Настроение +/− — `FloatText` с иконкой (`Fx/MoodUp` / `Fx/MoodDown`), шкала настроения — `Punch`.
- **Ловушка поймала вора/волка** — `HitStop` 0.08 → `Shake` клетки 20 px → `Fx/Shield` → `FloatText "+5"` с `Icons/Gold` → монеты `FlyTo` в счётчик золота (3–5 штук с разбросом 0.05 с) → `CountTo` золота. Это главный «вкусный» момент, сделай его хорошо.
- **Вор дошёл до сокровищницы** — `ScreenShake` 12, клетка `Flash` красным, монеты улетают **из** счётчика к краю экрана.
- **Комната сломана** (`RoomBroken`) — `ScreenShake` 16 + `Fx/Dust` + плитка `Shake` и потемнение, затем появляется `Crack` с `PopIn`
  (если уже сделан шейдер растворения — сначала растворение).
- Гость доволен — `Fx/Heart` + монеты `FlyTo` в золото. Недоволен — сердце репутации `Shake` + `Flicker`, `FloatText "−1"` с `Icons/Heart` красным.
- Призрак / Хозяин дома — `Fx/GhostSmoke` при каждом шаге, у Хозяина ещё `ScreenShake` 8 при появлении.
- Конец ночи — итоги: строки появляются по очереди `PopIn` с шагом 0.12 с, числа `CountTo`.

**Интерфейс**
- Все кнопки: нажатие — `DOScale(0.94)` за 0.06 с, отпускание — `Punch` 0.08. Сделай это в `UIKit.Button` один раз, а не в каждом месте.
- Окна (лавка, награды, колода, итоги, настройки) — `PopIn` содержимого + затемнение фона `DOFade`; закрытие — `PopOut`.
- Награды на выбор — карты выезжают по очереди с `OutBack`, выбранная — `Punch` + `Fx/Sparkles`, остальные — уезжают вниз и тают.
- Победа — `SlowMo` + `Fx/BeamGold` за заголовком + `Icons/Trophy` `PopIn`. Поражение — заголовок `Shake`, `Icons/Skull` `PopIn` без подскока.

## Блок 3. Вибрация

Сейчас в `Sfx` есть `Vibrate()` (вызывается в `Trap`, `Break`). В WebGL на iPhone вибрации нет вовсе (Safari не поддерживает Vibration API),
на Android Chrome — есть через `navigator.vibrate`.
- Сделай три уровня: `Haptic.Light()` (карта легла, кнопка) 10 мс, `Haptic.Medium()` (поимка, недовольный гость) 25 мс, `Haptic.Heavy()` (поломка, вор украл) паттерн [30, 40, 30].
- WebGL — через `.jslib` с проверкой `if (navigator.vibrate)`; в редакторе — ничего.
- Переключатель «Вибрация» в настройках рядом со звуком (иконку можно временно взять `SoundOn/Off`).

## Проверка в конце

1. Поимка вора ощущается «вкусно»: пауза → удар → щит → монеты летят в счётчик → счётчик докручивается.
2. Частые события (шаги гостя, много ловушек подряд) не копят твины: нет дрожания, «уползания» элементов и роста масштаба.
   После серии эффектов все элементы на своих местах и в масштабе 1.
3. «Меньше эффектов» реально убирает тряску и паузы.
4. На телефоне (WebGL) нет просадок FPS во время ночи.
5. Логика ночи не зависит от `HitStop/SlowMo` (итоги те же, что и без эффектов).
6. Коммиты по блокам, в конце — короткий список, что сделано.
