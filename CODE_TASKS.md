## Блок 1. Читаемость на телефоне — САМОЕ ВАЖНОЕ

Тест на itch с iPhone: ничего не читается. Причина — эталон 1080 px по ширине, телефон ~390 pt, всё уменьшается в ~2,8 раза:
текст 18–24 px превращается в 6–8 pt. Читаемый минимум — 11–12 pt.

1. **Шрифты в `Layout.PortraitLayout`** (`GameView.cs`): обычный текст **не меньше 32**, заголовки и цифры **40+**.
   Ориентир: `BodyFont 34, LogFont 32, StatsFont 44, ButtonFont 40, TileFont 30, CardNameFont 34`.
   Лог — 1 строка. Проверь все места, где от этих размеров вычитают (`L.CardDescFont - 7` и т.п.), чтобы минимум не упал ниже 26.
2. **Горизонталь на телефоне** — сейчас самое плохое место (`LandscapeLayout`, `MatchWidthOrHeight = 1`, шрифты 14–19 → 5–7 pt).
   Если короткая сторона экрана < ~600 pt (`Screen.height / (Screen.dpi/160)` или по соотношению Screen.height к reference),
   использовать третий макет `LandscapePhoneLayout`: шрифты ×1.8 от текущих горизонтальных, правая панель шире (~34% ширины),
   карты в руке крупнее. Пока сложно — допустимо временно на таких экранах показывать вертикальный макет с полями.
3. **Плашки под текстом поверх арта.** Строка статуса, блок «Соперник / В руке / Ночью гостей», лог, подсказки — всё, что лежит на фоне локации,
   кладётся на `Panels/Plate` (color.a ≈ 0.85). Обводку текста (`UIKit.Outlined`) поднять с 2 до 3.
4. **Затемнение фона локации** на игровом экране: поверх `Locations/<Id>` чёрный слой alpha ~0.3 + виньетка (края темнее, ~0.55).
   Доска и карты должны быть самым светлым на экране.
5. **Карты в руке** — описание не читается при любом шрифте (карта ~80 pt шириной). В руке оставить: арт, **крупное** название на ленте,
   схему дверей. Пергамент с описанием в руке скрыть (или оставить пустым). Описание — в просмотре карты (Блок 3).
6. **Подписи на плитках поля** («Прихожая» под иконкой) убрать; название — по тапу на клетку (короткий тост над клеткой или тот же просмотр).
7. **Строка статуса**: только «Ходов: 2 · Рука 5/10». Длинную подсказку «День: построй комнаты, пока гости не пришли» показывать только в
   обучении / первых двух уровнях.
8. **Кнопка меню** (`GameView.cs`, `menuButton = UIKit.Button(root, "≡", …)`) показывает пустой квадрат — символа ≡ нет в Noto Sans.
   Заменить на `ButtonRound` + `Icons/Menu`. Проверь заодно все строки на символы, которых нет в шрифте (✓ в лавке и т.п.) — заменить иконками.

**Проверка блока:** сборка WebGL, скриншоты вертикали и горизонтали в эмуляторе iPhone (390×844) — любой текст ≥ 11 pt.

## Блок 3. Просмотр карты с оборотом

Сейчас крупный просмотр есть только для гостей (`Inspect(GuestDef)` в `GameView.Overlays.cs`: затемнение 0.7, карта ×2.2, `Pop`).
У карт комнат в руке его нет. Нужен единый просмотр для **комнат и гостей**:

- **Как открыть:** гость — тап (как сейчас). Карта комнаты в руке — **долгое нажатие ~0.35 с** без движения
  (в `HandCard` уже есть `OnPointerDown/Up`; тап и перетаскивание должны работать как раньше; если палец сдвинулся больше ~12 px — это drag, не просмотр).
  Карты в наградах / лавке / колоде / наследстве — тоже долгое нажатие (обычный тап там = выбор).
- **Анимация открытия (~0.6 с):**
  1. Затемнение 0 → 0.7 за 0.25 с (чёрно-фиолетовое, как в `Overlay`).
  2. Копия карты появляется **на месте исходной** (переведи её позицию в координаты оверлея), исходную в руке спрячь (alpha 0).
  3. Одновременно: полёт в центр (`OutCubic`), масштаб до ~2.6 (`OutBack`), **полный оборот по Y на 360°**.
     На 90° показать **рубашку** (`CardBacks` — для комнат рубашка игрока, для гостей — соперника), на 270° снова лицо —
     так видно, что крутится двусторонняя карта. (Canvas — Screen Space Overlay, перспективы нет: поворот по Y выглядит как сжатие по ширине — это ок.)
  4. В конце `Sfx.Card()` и вспышка за картой: `Fx/Sparkles`; для круга ≥ Эпичная — `Fx/BeamGold`.
  5. Пока открыта — лёгкое «дыхание»: наклон по Z ±2° и смещение по Y ±6 px, `InOutSine`, бесконечно (`SetLink`).
- **Под картой:** название крупно (44+) и полное описание на `Panels/Plate` или пергаменте — **читаемым шрифтом 34+** (в этом весь смысл просмотра).
  Для комнаты — ещё схема дверей и уровень. Подпись «Коснись, чтобы закрыть».
- **Закрытие:** тап в любом месте → та же анимация в обратную сторону (с оборотом), карта возвращается на исходное место, исходная снова видна.
- Во время обучения не ломать `tutorial.BringToFront()`.
- Сделай это отдельным файлом `GameView.Inspect.cs`, а старый `Inspect(GuestDef)` переведи на новый механизм.

## Блок 4. Шейдеры (Shader Graph, цель Canvas / UI — Unity 6 это умеет)

Папка `Assets/Shaders/`. Всё должно работать в WebGL на телефоне: без пост-обработки, без лишних проходов, простые текстуры шума.

1. **Блик по рамке (`UI_Foil`)** — для `Frames/Frame<tier>`:
   полоса света наискосок пробегает по рамке раз в 3–5 с (время + сдвиг по UV, маска = альфа рамки).
   Круги 0–3 — без эффекта, 4–6 — белый блик, 7 (Эпичная) — блик чаще и ярче, 8 (Легендарная) — **радужная голография**
   (оттенок по UV + времени), в руке слегка зависит от наклона карты. Параметры: скорость, ширина, интенсивность, радужность.
2. **День → ночь (`UI_NightGrade`)** — материал на фоне локации:
   параметр `_Night` 0..1 сдвигает цвета к синему, снижает насыщенность и яркость, усиливает виньетку;
   **тёплые светящиеся места** (окна, фонари) остаются яркими — маску можно получить без отдельной картинки:
   по яркости и «теплоте» пикселя (высокий R и G, низкий B). Плавно анимировать `_Night` при переходе к ночи и обратно (DOTween по свойству материала).
   Это заменит/усилит текущие `BuildNightSky` / `FadeNightSky`.
3. **Растворение (`UI_Dissolve`)** — по текстуре шума, с золотым светящимся краем:
   комната ломается → плитка частично «прогорает» перед появлением `Crack`; сыгранная карта гостя растворяется;
   ушедший гость/пойманный вор исчезает. Параметр `_Dissolve` 0..1, анимировать DOTween.
4. (если останется время) **Обесцвечивание** для закрытых домов кампании и неполученных рубашек вместо затемнения цветом.

UI-материалы — отдельный экземпляр на объект только там, где параметр анимируется индивидуально; иначе общий материал.
Если Shader Graph Canvas-цель недоступна в WebGL-сборке — написать вручную как UI-шейдер (на базе `UI/Default`, с поддержкой маски и `RectMask2D`).
